# Замер — Android-приложение

Эскизы обмеров на объекте с экспортом в DWG/DXF. Приложение — `www/index.html`,
обёрнутое в Capacitor; «Отправить» открывает системное меню Android
(Telegram, WhatsApp, почта) с настоящим файлом .dwg.

APK собирается автоматически при каждом обновлении ветки `main`
(вкладка **Actions**). Готовый файл — в разделе **Releases**: `Zamer.apk`.
