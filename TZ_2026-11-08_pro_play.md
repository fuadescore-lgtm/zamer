## 3.0.7 — fail closed (10.11.2026, по запросу владельца)
- Причина «Pro без подписки» в 3.0.6: проверка в JS была открыта по умолчанию (ENT.on=false) и включалась только в конце запуска (entInit). Если она не включилась, всё было открыто как вне приложения. Теперь ограничения включены с первой строки (ENT.on по наличию Capacitor), режим до ответа — 'wait' (экспорт закрыт).
- Локальный пробный период на устройстве (14 дней) убран (JS и BillingPlugin.java). Пробный период — только предложение (offer) Google Play с бесплатной фазой; приложение показывает его рядом с планом и покупает по токену этого предложения.
- Pro = entProOK(): подтверждённый ответ Play (pro===true и checked) или активная запись белого списка (плагин Whitelist; пока его нет → «Firebase не подключён» → нет доступа). Нет плагина / ошибка / нет товара / нет ответа 20 с → режим 'view'.
- BillingPlugin: после покупки — только полный ответ queryPurchases (иначе подписанный кэш ≤ 7 дней); покупка учитывается только для своего packageName.
- Окно Pro показывает строку «Проверка: Google Play — …; белый список — …». Исправлен бесконечный цикл загрузки цен, когда товара нет в Play.
- Белый список (Firebase): план — Google-вход (Credential Manager) + Firestore `whitelist/{email}` {active:true, until?:Timestamp}, правила: чтение только своей записи, запись — только из консоли; кэш ≤ 7 дней в подписанных настройках. Подключение — после google-services.json от владельца.
